# rx/drug-storage

Three.js viewer for the pharmacy drug-storage area. Plain ES modules with a
version-pinned Three.js import map; no build step.

## Model

`assets/drug-storage-area.glb` is exported from the Blender scene in
`~/projects/drug-storage-temp` (the scene `render_shadows_blender.py` builds
from `generated/scene.obj`, minus its camera and sun):

```sh
cd ~/projects/drug-storage-temp
blender -b --python-exit-code 1 -P export_glb.py -- \
  ~/projects/destructographic.github.io/rx/drug-storage/assets/drug-storage-area.glb
```

- Units: 1 glTF unit = 1 inch (not metres). The viewer does not rescale; the
  camera, clipping planes, controls and shadow are fitted to the model bounds.
- Axes: Y-up (the exporter converts from Blender Z-up).
- 92 flat, named `Vis3D_*` mesh nodes (67 room/fixture + 25 millwork caps),
  28 untextured materials, 1684 triangles, about 141 KB.
- Initial view and sun direction match `camera.py` and `TO_SUN` in
  drug-storage-temp, so the first frame resembles `render/latest.png`
  (perspective here, orthographic there).

## Uniweb textures

`assets/textures/uniweb/` holds hook-channel normal maps plus `manifest.json`,
generated by `uniweb_textures.py` in drug-storage-temp (see its README for
parameters). `uniweb.js` applies them after the model loads:

- Uniweb meshes are found by name (`Uniweb_*_P#`, `*_Panel(s)`, `*EndCap*`).
  Big faces get planar UVs from world positions: u spans one panel, left to right
  as seen from that side, and v = height / 84 in. The GLB has no UVs and is not modified.
- Multi-panel freestanding runs are split at their existing panel joints. Each
  segment's width (±0.05 in) selects the map, so Fixture D uses 48 and 32 in maps.
  Edges and tops use a plain material.
- Each file loads once and is shared. Every Uniweb mesh has its own
  `MeshStandardMaterial` array (no colour map, metalness 0), so
  `material.color` can be changed per mesh, e.g. for a yellow hover.
- `NORMAL_SCALE` and `PAINT` at the top of `uniweb.js` tune strength and finish.
- `?debug` exposes `window.viewer` (`scene`, `camera`, `controls`, `renderer`).

## Millwork caps

25 `Vis3D_Cap_*` meshes, one per Uniweb panel (`Vis3D_Cap_Back_P3`,
`Vis3D_Cap_Fixture_D_P2`, …), built by drug-storage-temp `build_model.py`:
hollow 3 × 3 in channels on fixtures, solid-backed L sections on the walls.
Each has its own wood-tan `MeshStandardMaterial` (`cap_<run>_P<n>`), so
`material.color` can be changed per segment. `userData` (glTF extras) links
each one to its panel and bases:

- `cap_panel`, `cap_panel_index`, `cap_panel_count`: the Uniweb panel mesh.
  Fixtures D, F and G have one panel mesh per run, so the index and
  `cap_panel_range_in` (plan inches along `cap_axis`) select the panel within it.
- `cap_bases`: comma-separated base mesh names; `cap_run`, `cap_segment`.

The names do not match `uniweb.js` patterns, so caps are untextured. No viewer code changed.
